## 🎓 **Repository Best Practices:**

### **Commit Messages:**
✅ **Good:**
```
"Added budget popup alert"
"Fixed simulate scan error"
"Updated theme to Typeform style"
```

❌ **Bad:**
```
"changes"
"update"
"fix"
```

### **Commit Frequency:**
- Commit after each feature
- Commit when something works
- Don't commit broken code
- Push regularly

### **Branch Strategy:**
- `main` - stable, working code
- `develop` - active development
- `feature/name` - new features
- `fix/issue` - bug fixes
